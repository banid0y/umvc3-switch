# Controles

Os ícones de botão do jogo aparecem no padrão do Switch (pasta `umvc3/texturas/` no cartão).

## Menus

| Botão | Ação |
|---|---|
| A (direita) | Confirmar |
| B (baixo) | Voltar |
| Direcional ou analógico esquerdo | Mover |

## Luta (configuração padrão do jogo)

| Botão do Switch | Golpe |
|---|---|
| Y | Ataque fraco (L) |
| X | Ataque médio (M) |
| A | Ataque forte (H) |
| B | Especial (S) |
| L | Assistente 1 |
| R | Assistente 2 |
| ZL | Assistente 1 + 2 |
| ZR | L + M + H |

Dá para trocar em OPTIONS → CONTROLLER, dentro do jogo.

## Dois jogadores

Ao escolher VERSUS, o Switch abre a tela de controles do sistema. Valem dois controles completos (Pro Controller,
par de Joy-Con) ou **um Joy-Con deitado para cada jogador**. Com o Joy-Con deitado, o analógico e os quatro botões
de face já vêm girados para a posição em que você segura; SL e SR fazem os dois assistentes.

## Atalhos do port

| Atalho | Ação |
|---|---|
| L3 + R3 por 1 segundo | Menu do port: medidor de quadros, ligar/desligar a CE, reiniciar, sair |
| R3 + MENOS | Liga ou desliga o medidor de quadros |
| L3 + MENOS | Grava uma captura da tela em `umvc3/userdata/` |
