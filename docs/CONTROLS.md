# Controls

The game's button icons are shown in Switch style (the `umvc3/texturas/` folder on the card).

## Menus

| Button | Action |
|---|---|
| A (right) | Confirm |
| B (bottom) | Back |
| D-pad or left stick | Move |

## Fights (the game's default layout)

| Switch button | Move |
|---|---|
| Y | Light attack (L) |
| X | Medium attack (M) |
| A | Heavy attack (H) |
| B | Special (S) |
| L | Assist 1 |
| R | Assist 2 |
| ZL | Assist 1 + 2 |
| ZR | L + M + H |

You can change this in OPTIONS → CONTROLLER, inside the game.

## Two players

When you choose VERSUS, the Switch opens the system controller screen. Two full controllers work (Pro Controller,
Joy-Con pair), and so does **one sideways Joy-Con per player**. With a sideways Joy-Con the stick and the four face
buttons are already rotated to match how you hold it; SL and SR are the two assists.

## Port shortcuts

| Shortcut | Action |
|---|---|
| L3 + R3 for 1 second | Port menu: frame counter, CE on/off, restart, quit |
| R3 + MINUS | Turns the frame counter on or off |
| L3 + MINUS | Saves a screenshot to `umvc3/userdata/` |
